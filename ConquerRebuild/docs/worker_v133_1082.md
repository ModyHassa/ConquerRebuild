# 1082 — the couple/mate action family (52 rows) — token vocabulary decoded

Case body `0x14012f025`. **52 rows**, the largest undecoded type.

## What is proven

- `sscanf` of the action param with fmt `0x14070f080` = **`"%s %s %u %d %d %d"`**, requiring
  **>= 6** conversions (two token strings + one unsigned + three ints).
- The **token vocabulary** (every `strcmp` against a literal in the body):

| token | `.rdata` |
|---|---|
| `self` | 0x14070f078 |
| `couple` | 0x14070f068 |
| `mate` | 0x14070f070 |
| `chk` | 0x14070f390 |
| `add` | 0x14070f2d0 |

- The body then repeats one shape four times, once per `(token1, token2)` combination:

```
mgr = 0x1401181a0()                     ; a manager singleton
mgr->vt[0x8]() / mgr->vt[0x10]()        ; two manager slots, called with the parsed ints
0x140008520(ctx) -> 0x140087650()       ; world object lookup (by an id from the parse)
...->vt[0x48]()                         ; the looked-up object's value
user->vt[0x2d8](index)                  ; the STATUS BITMAP query (same slot 1096/1116 use)
user->vt[0x98]()
```

So 1082 is the **couple / mate relationship action**: the first token selects the subject
(`self` = the player, `couple` = the pair, `mate` = the partner), the second selects the operation
(`add` / `chk`), and the three ints are the operands. The manager at `0x1401181a0` is the couple
manager (it also drives the `team_athlete_*` / `athlete_*` columns: a couple is tracked as a team).

## What still blocks the port
1. **`0x1401181a0`'s class and the meaning of its `vt[0x8]` / `vt[0x10]` slots.** Both are invoked
   with the parsed ints and their results are compared, so the four branches cannot be written
   without knowing whether the slot is "get couple id", "get partner id" or "count members".
2. `user->vt[0x2d8]` is the status-bitmap query (verified elsewhere) but the index used here is one
   of the parsed ints, so the mapping "which status index means 'in a couple'" is still open.
3. The rebuild has **no couple/mate model** (`src/systems/team.hpp` exists but models teams, not
   couples).

**Port verdict: BLOCKED** on the couple manager (`0x1401181a0`) + the couple model. The token
grammar above is complete, so the port is mechanical once the manager's four slots are named.

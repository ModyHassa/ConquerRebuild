## 3. Per-element work and call targets (VERIFIED)

## 4. Branch outcome (VERIFIED)
- Parse failure (sscanf < 2): 0x140147d59 builds the error path — `[rbp]` -> `[vtable+0x20]` (packet id) ->
  `[vtable+0x40]`, logged with 'table:cq_action/cq_newaction, ACTION %u: ...parameter count...' @ 0x140147d7a and
  line number 0x3291 (12945) @ 0x140147d83, then `jmp 0x140148aa6` (handler return).
- Parse ok: iterate the whole role container; `sil` (=1) is set only if some element matched all filters and was
  spawned. Return 0x140147ffe `mov al,sil` -> 0x140148001 `jmp 0x140148aa8`: **returns 1 if at least one NPC was
  spawned (not deduplicated — the loop continues after a success), 0 otherwise.**
- No early exit on success: the guard is `it != end`, not "stop after first hit".

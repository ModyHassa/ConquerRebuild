# v129 — 802 (lastentertime cooldown) and 1511 (CMsgAction 160), plus the CUser+0xE78 probe

## 802 — case 0x6e, body 0x1401329bf (VERIFIED, ported)
The literal "ACTION_USER_CHECK_ITEM_IN_TRUNCK fail" is only the shared log string of the block;
the body is a **cooldown gate**, not an item check:

1. `sscanf(rsi, "%d", &v)` (fmt 0x14070c668), `cmp eax,1 ; jl` -> `log_InlineLogDBERROR` line
   **0x257c** -> return 0.
2. `edi = 0x140167070(user)` - the getter loads **`CUser+0x12c0`**, does
   `container->vt[0x20](0x140715c20)` and the string at `0x140715c20` is **`lastentertime`**
   (read out of .rdata at file offset 0x714220). The only three references to that key in the whole
   binary are this getter (0x140167085) and two inside the setter 0x1401787e0 (0x140178875 /
   0x1401788b8), so nothing else in the server reads or writes it.
3. `ecx = GetTickCount() - edi ; cmp v,ecx ; jge pass` then `test edi,edi ; je pass`
   -> pass when `stamp == 0` or `(int32)(now - stamp) >= v`, else return 0.
4. On pass: `0x1401787e0(user, now)` (which itself returns immediately when `now <= 0`) stores the
   fresh stamp; return 1. **No packet, no text, no DB.**

Port: `Player::last_enter_time` (u32 ms, 0 = never), the same u32 wrap arithmetic, stamp refreshed
only on a pass.

**UNKNOWN:** the class of the `npc->[0x60]` sub-object, so that slot is written 0 (the notes in
`docs/worker_v126_g5_1508.md` allow exactly this).

## CUser+0xE78 (what 1557 still waits on)
* `0x140165970` = `add rcx,0xe78 ; jmp 0x140373950` and `0x140373950` is `mov 0x1b0(%rcx),%eax ; ret`.
* `0x140165960` = `add rcx,0xe78 ; jmp 0x140371db0` and `0x140371db0` is `mov 0xa8(%rcx),%eax ; ret`.
* So `CUser+0xE78` is the base of an **embedded object**, and 1557's day stamp is
  `DateStamp(*(u32*)(user+0x1028))` with a fallback to `*(u32*)(user+0xF20)`.
* No writer of `0xf20(%r*)` exists in the module and the `0x1028(%r*)` writes all sit in
  0x140005xxx (a different class), so the two fields are **not identified**. The object is also
  used by 0x140371860 / 0x140373860 / 0x140373950 (compare/dispatch helpers) and by the
  old-engine pass at 0x140130bff/0x140130c35. **1557 stays BLOCKED** on naming this block.

# Project docs

These files are generated copies of the working docs kept next to the repo,
synced at the end of every wave:

- `HANDOFF.md` - where the port stands and what is next
- `CHANGELOG.md` - per-wave record
- `DEFERRED_TYPES.md` - decoded-but-blocked action types with their evidence
- `ACTION_COVERAGE.md` - per-type row coverage of the content tables
